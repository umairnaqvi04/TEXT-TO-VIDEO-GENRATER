# Text to Video (Local)
1. Python 3.10+ install karein.
2. VS Code terminal mein is folder mein jayein:
   python -m venv venv
   venv\Scripts\activate        (Mac/Linux: source venv/bin/activate)
   pip install -r requirements.txt
3. Chalayein:  streamlit run app.py   (browser mein http://localhost:8501 khulega)
4. Script likhein: har line = "visual prompt | narration" (# se shuru hone wali lines ignore hoti hain). Urdu narration ke liye Urdu voice use karein.. Generate dabayein.
Output: output/final.mp4
